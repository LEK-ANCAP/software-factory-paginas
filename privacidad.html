Política de privacidad

Software Factory · Última actualización: 9 de noviembre de 2026

Quién la usa

Software Factory es una herramienta personal de Miguel Ángel de la Vega. Solo la usa él, con su propia cuenta de Google. No tiene más usuarios.

Qué datos de Google lee

Con el permiso de solo lectura de Google Docs, Software Factory abre las notas de reunión que Google Meet guarda en el Drive de esa cuenta, cuando llega el correo de Google que avisa de ellas. No crea, no modifica y no borra ningún documento.

Para qué los usa

Lee el texto de cada nota para hacer un resumen de la reunión y proponer las tareas que salieron de ella. Para eso envía el texto a Claude, el modelo de inteligencia artificial de Anthropic, que lo procesa y devuelve el resumen y las tareas.

Qué guarda y dónde

Guarda el resumen, las tareas propuestas y el enlace al documento original en un servidor privado del propietario. No guarda copias de otros documentos.

Con quién se comparte

Con nadie más, salvo el envío a Anthropic descrito arriba para procesar el texto. Los datos no se venden, no se usan para publicidad y no se ceden a terceros.

El uso de la información recibida de las API de Google se ajusta a la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de Uso Limitado.

Cómo retirar el permiso

El permiso se puede retirar en cualquier momento desde la página de permisos de tu cuenta de Google. Desde ese momento, Software Factory deja de poder leer los documentos.
